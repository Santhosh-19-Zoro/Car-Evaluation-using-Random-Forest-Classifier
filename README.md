# Car-Evaluation-using-Random-Forest-Classifier
This project applies Machine Learning techniques to evaluate car acceptability levels based on key automotive attributes such as buying price, maintenance cost, safety level, luggage capacity, and passenger capacity.
The main goal is to build a Random Forest Classifier that can predict whether a car is unacceptable, acceptable, good, or very good — providing a data-driven decision support system for the automotive industry.

The project integrates Python (Scikit-learn) for model development and Power BI for interactive visualization and interpretation of model insights.
